# CreaThemis

### Independent Software & Game Development Studio

**CreaThemis（クリエイテミス）** is an independent development studio focused on game development, software engineering, developer tools, and technical research.

CreaThemisは、ゲーム開発・ソフトウェア開発・開発支援ツールの制作・技術研究を中心に活動する個人開発スタジオです。

---

## About / 概要

CreaThemis aims to create software that combines creativity, functionality, and technical exploration.

創造性と実用性、技術的な探究心を大切にしながら、ゲームやソフトウェアの企画・設計・開発に取り組んでいます。

## Development Areas / 開発分野

### 🎮 Game Development
**ゲーム開発**

Development of original games, gameplay systems, and related technologies.

オリジナルゲームの制作、ゲームシステムの設計・実装、および関連技術の開発。

### 💻 Software Development
**ソフトウェア開発**

Development of desktop applications, web applications, and utility software.

デスクトップアプリケーション、Webアプリケーション、各種ユーティリティの開発。

### 🛠️ Developer Tools
**開発支援ツール**

Development of libraries, frameworks, command-line tools, and utilities that improve development workflows.

ライブラリ、フレームワーク、CLIツールなど、開発作業を支援するソフトウェアの制作。

### 🔬 Research & Engineering
**技術研究**

Exploration of programming languages, game engines, software architecture, and emerging technologies.

プログラミング言語、ゲームエンジン、ソフトウェアアーキテクチャなどの技術研究。

- **Independence / 独立性**：自分たちの発想を形にする。
